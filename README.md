# Shiru Italian Streaming Extensions

Estensioni per Shiru che permettono di cercare e riprodurre anime in streaming italiano da:
- AnimeWorld (animeworld.ac)
- AnimeSaturn (animesaturn.net)
- AnimeUnity (animeunity.so)

## Installazione

Aggiungi questo repository in Shiru:# shiru-italian-streaming
