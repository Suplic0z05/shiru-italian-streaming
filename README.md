# Shiru Italian Streaming Extensions

Estensioni per [Shiru](https://shiru.app/) che permettono di cercare e riprodurre anime in streaming italiano da:
- [AnimeWorld](https://www.animeworld.ac)
- [AnimeSaturn](https://www.animesaturn.net)
- [AnimeUnity](https://www.animeunity.so)

## Installazione

Apri Shiru e vai nella sezione Estensioni (`shiru.app/#/extensions`).

Aggiungi questo repository incollando una delle seguenti voci:

- `gh:Suplic0z05/shiru-italian-streaming` (repository completo con tutte le estensioni)
- `gh:Suplic0z05/shiru-italian-streaming/animeworldsearch` (solo AnimeWorld)
- `gh:Suplic0z05/shiru-italian-streaming/animesaturnsearch` (solo AnimeSaturn)
- `gh:Suplic0z05/shiru-italian-streaming/animeunitysearch` (solo AnimeUnity)

## Utilizzo

Una volta installate, le estensioni appariranno automaticamente come fonti quando cerchi anime in Shiru. Le estensioni:

- Cercano automaticamente l'anime sul sito corrispondente
- Trovano l'episodio specifico richiesto
- Restituiscono il link diretto allo stream video

## Note

- Tutte le estensioni sono configurate per la regione Italia (IT)
- I siti possono cambiare struttura nel tempo, se un'estensione smette di funzionare controlla gli aggiornamenti
- Alcune fonti potrebbero richiedere cookie o autenticazione per funzionare correttamente
